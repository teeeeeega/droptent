# Droptent

A geographic search engine for finding where to sleep outdoors.

> The territory itself is the database.

## What is Droptent?

Droptent analyzes geographic data and scores the territory
according to how suitable it may be for sleeping outdoors.

The goal is simple:

MAP → ANALYSIS → ZONE → SCORE → PLACE

Droptent is not a database of camping spots.
The territory itself is the database.

## Current status

🚧 Early development

Currently implemented:
- DEM terrain analysis
- slope analysis
- land-cover analysis
- terrain suitability scoring
- water proximity
- road accessibility
- tracks and trails
- protected-area information
- built-up area penalty
- candidate-zone extraction
- candidate-zone ranking
- first local map visualization
